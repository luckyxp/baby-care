# 内置素材库

当前共 860 项可浏览素材，另有 11 套月龄阶段方案和 12 条喂养原则。

| 类型 | 数量 | 内容与组织方式 |
| --- | ---: | --- |
| 早教活动 | 500 | 大运动、精细动作、感官认知、语言启蒙、社交各 100 条 |
| 亲子互动 | 120 | 日间 48 条、晚间 72 条，均标注适用月龄与执行提示 |
| 食材 | 120 | 8 个食物分组，包含推荐起始月龄、常见过敏原与处理方式 |
| 辅食食谱 | 120 | 从 6 月龄细泥到 24 月龄以上软烂家常餐，包含用量、步骤、质地与过敏原 |

早教与亲子互动覆盖 0–36 月龄。推荐月龄采用 `[min, max)`；食材和食谱以 `min <= 宝宝月龄` 筛选。年龄区间用于日常推荐，实际活动、质地和时长还需结合宝宝当前能力、兴趣与状态。每项活动的时长可以缩短或分多次完成，不要求每天完成所有领域。

素材库页面显示当前结果数与全库总数。默认筛选宝宝当前月龄，打开“全部月龄”可浏览全部内容；搜索覆盖标题、目标、材料、步骤、观察要点或执行提示，食谱还可按质地和过敏原搜索。

统一入口为 `index.ts`。早教拓展内容按五大领域放在 `edu/`；亲子、食材和食谱分别放在 `interaction-extra.ts`、`foods-extra.ts`、`recipes-extra.ts`，经各主文件汇总。数据为明确的静态条目，不依赖联网下载或运行时排列组合生成。新增条目使用固定 ID，活动与食谱可通过 `findLibraryItem` 反查，并直接参与每日计划推荐、轮换与素材挑选。

内容编写采用以下照护原则：

- 清醒俯卧必须全程看护；困倦后结束活动，仰卧放回平整坚实、无松软杂物的睡眠面。
- 尊重主动动作与拒绝，不通过拉手腕坐起、上下提拉、抛举或高处跳落完成动作。
- 玩具选择不可吞咽、无脱落部件的适龄产品；布料不遮口鼻，绳带不成环套身体；涉水时成人不离开手边。
- 辅食约满 6 月龄且具备相应准备度时开始；质地随吞咽咀嚼能力调整，月龄达标不自动意味着可以吃块状食物。
- 组合食谱先确认各食材分别耐受；所有食物均可能致敏，常见过敏原标记不代表其他食物绝不会过敏。过敏高风险宝宝的引入安排需咨询医生。
- 食材推荐月龄对应本库的处理形态，不应被解读为必须延迟引入过敏原。整粒坚果、果核、整颗圆果等不直接提供，坚果酱必须充分稀释，肉蛋水产彻底熟制并检查骨刺。
- 食谱用量为制作参考，不要求吃完；坐稳进食并全程看护，不把点心或果泥替代奶及富铁正餐。

活动为日常照护编写，以下资料用于核对通用安全原则，不能视为对每条活动或配方的医学认证：

- AAP / HealthyChildren：[Back to Sleep, Tummy to Play](https://www.healthychildren.org/English/ages-stages/baby/sleep/Pages/back-to-sleep-tummy-to-play.aspx)
- CDC：[When, What, and How to Introduce Solid Foods](https://www.cdc.gov/infant-toddler-nutrition/foods-and-drinks/when-what-and-how-to-introduce-solid-foods.html)
- CDC：[Choking Hazards](https://www.cdc.gov/infant-toddler-nutrition/foods-and-drinks/choking-hazards.html)

`tests/library.test.ts` 检查数量下限、ID 与标题唯一性、字段完整性、月龄覆盖、常见过敏原和条目反查。运行 `npm test` 验证与计划等其他模块的集成，运行 `npm run build` 验证类型与静态打包。
